# Validation — 2026-09-12

Validated on the source Linux machine with Python 3.14 and PySide6 6.11.2:

- 25 engine, topology, smoothing, food lifetime and native Cairo renderer tests
  pass. The same suite detects and skips the 3 Qt-only tests when Qt is absent.
- All 3 Qt tests pass in an isolated virtual environment: Windows command-line
  conventions, matching pixels on both sides of a monitor seam, and complete
  food/glow fading to black.
- Portable application starts, animates, and exits on its timer using Qt's
  offscreen platform.
- Linux installer tested with an isolated target and launcher paths containing
  spaces; the installed launcher also passes the offscreen smoke check.
- Linux installer shell syntax passes. The source parses and compiles.
- `preview.png` was generated by the portable Qt renderer with six snakes.

Not verified on this Linux machine:

- Native Windows PowerShell execution, PyInstaller `.scr` building, Windows
  embedded preview, and mixed-DPI Win32 monitor enumeration. The Windows
  installer builds on the target PC; no untested Windows executable is bundled.
- Automatic idle integration for arbitrary Linux desktops. That setup is
  intentionally separate from application installation and is documented.

The installed Omarchy screensaver on the source computer remains unchanged.
